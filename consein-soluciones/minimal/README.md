# Consein · Soluciones — versión minimalista (estándares corporativos)

Salida ejecutable: `../consein-soluciones-minimal.html` (un solo archivo; abrir con doble clic).

- `content.json`: todos los textos (primera persona, títulos cortos, title/meta SEO por página).
- `template.html`: diseño minimalista y lógica (rutas, subpantalla «Seguir leyendo…»).
- `build.py`: genera el HTML final → `python3 build.py`.

## Tipografías
- Títulos: **Haltto** (fuente con licencia). Copie `Haltto-Bold.woff2` / `.otf` (y `Haltto-Regular`) en una carpeta
  `fonts/` junto al HTML, o instálela en el equipo. Sin la fuente, los títulos usan Poppins.
- Párrafos: **Poppins** (Google Fonts).
